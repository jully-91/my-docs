## 关于我

我是 GitHub 用户 jully-91，正在学习用 Markdown 整理技术内容，并尝试通过 GitHub Pages 发布文档。我创建这个网站，是为了记录这次 MkDocs 自动部署实践，也方便自己回顾从本地预览到公开发布的过程。网站目前包含项目介绍、使用指南和 API 文档示例；后续我会根据学习情况继续完善内容。

## 实践体会

这次实践中，我先在本地编写和预览文档，再通过 GitHub Actions 将网站发布到 GitHub Pages。过程中，我曾把配置文件名写错，也输错过 Python 命令；对照文件结构和终端报错后，我逐一修正了问题。第二次修改首页并推送后，Actions 自动运行，公开网站也出现了新增内容，让我更清楚地理解了文档从源码到网页的发布过程。
